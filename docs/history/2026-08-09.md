## 第五阶段：Web 界面 + 多模型对比（当晚）

**Web 界面（src/web.js + web/index.html）**：
- 零依赖 node:http 服务器 + 原生前端单文件；生成任务跑子进程（spawn node src/cli.js），stdout/stderr 流式进任务日志，前端 2s 轮询
- API：/api/projects、POST /api/generate、/api/jobs/:id（状态+日志）、/api/files/:id、/api/file/:id?path=（防目录穿越）、POST /api/preview/:id（拉起 mdbrowse）
- 端到端验证通过：b01-hello-cli 任务 → 7 章（完整度 92.7 S，¥0.31）；命令 npm run web（默认端口 8787）

**多模型对比（benchmarks/models.json + compare-models.js）**：
- 同项目（hello-cli）× 3 配置：deepseek-chat / deepseek-reasoner / chat+reasoner-review，标准评测模式；输出 compare-<ts>/compare-report.md

**踩的大坑**：compare-models.js 默认项目名写成 hello-cli，但样例目录叫 b01-hello-cli → 扫描空目录 → 概况"未命名项目" → 教程写成 Flask 假项目（可信度 24，全 C 级）。修复：resolveSampleDir 精确+短名模糊匹配+不存在报错；web.js 也加了同样逻辑。修后 deepseek-chat 81.3（A）。

**最终实测结果**（hello-cli）：
| 配置 | 耗时 | 成本 | 完整度 | 可信度 | 质量分 |
| deepseek-chat | 5.8min | ¥0.60 | 91.9 | 64.7 | 78.3(B) |
| deepseek-reasoner | 20.5min | ¥3.70 | 77.4 | 81.6 | 79.5(B) |
| chat+reasoner-review | 20.1min | ¥1.59 | 93.7 | 68.3 | 81.0(A) |
洞察：reasoner 当"写手"贵 6 倍且完整度低；reasoner 当"评审"是甜蜜点（混合方案一半成本拿最高分）→ 支撑默认 writer=chat + reviewer=reasoner 设计。

**教训**：基准/对比脚本的样例路径是易错点（前缀 b01- 等），统一用"短名模糊匹配 + 不存在即报错"模式。
