## 第二阶段：量化指标 + 真实验证 + 阈值修复闭环 + 模板/视觉（当天下午追加）

用户确认 P0 全部做（真实验证默认关闭、--verify 开启），P1 加视觉模型 API（MCP 留 v2），模板定制也做。核心新增需求：**分数低于阈值自动修改教程**。

**新增/修改**：
- `src/metrics.js`（新）：纯本地零 LLM 的六维指标——结构完整度（大纲小节关键词匹配覆盖率）、格式规范度（四级标题/代码块未闭合/表格列数/加粗配对 lint，从 100 扣分）、事实一致性（教程引用的文件路径与项目文件树比对命中率）、信息密度（字数+代码占比）；加权合成 0-100 QualityScore + S/A/B/C 等级；输出按章节归类的可枚举问题清单 issuesByChapter（阈值修复闭环的弹药）
- `src/verifier.js`（新，--verify 开启）：提取教程 bash/shell 代码块 → 过滤：危险命令（rm/chmod/sudo/磁盘写）、环境设置（export/cd）、报错文本（Error:/SyntaxError:/at）、控制流（for/do/done）、占位符 URL（yourname）、环境变量前缀（VAR=x cmd）→ 项目目录内就地执行（30s 超时）→ 可运行率
- `src/report.js`（新）：渲染 report.md（总分/等级/六维条形/问题清单/验证结果表/修复历史/与黄金样本 --baseline 对比）

- llm.js：重构出公共 requestCompletion()，新增 chatVision() 多模态（base64 图片）
- scanner.js：collectImages() 收集项目图片 + describeImages() 调视觉模型提取（无 vision 配置自动跳过）
- prompts.js：OUTLINER_SYS → buildOutlinerSys(template)，支持 --template 自定义章节
- outliner.js：generateOutline 支持 template；isValidTemplate 校验；兜底用模板
- reviewer.js：reviewAllChapters 返回 chapterScores（每章均分，供 metrics.review 维度）
- pipeline.js：新增阶段 5（量化评估+验证+修复闭环）；**修复闭环策略**：本地问题回灌 writer 重写 → 重算 → 分数未提升则**回滚旧版本并停止**（防越改越差）；验证失败命令并入问题清单

**联调结果（demo，--verify）**：
- v2 首次端到端：7 章生成+审查全过（8.5-9.0）；验证 57 条命令通过 26 条（45.6%）——抓到真实问题：教程用 --tags 但 demo 实际是 --tag、幻觉 git clone yourname URL、Windows 上 nvm 不可用；质量分 73.2 < 80 → 修复 2 轮（73.2→68.2→69.1），暴露两个缺陷后修复：①验证器把报错文本/控制流当命令执行 ②修复无改进仍继续、且验证失败未回灌
- v3 复验中（验证器过滤后只统计真实命令；修复闭环带回滚）

**教训/经验**：
- LLM 生成的教程命令 45% 在本机跑不通是常态（平台差异+幻觉），真实验证的价值正是抓这些；但 bash 风格代码块在 Windows 上大量误报，需过滤规则
- 修复闭环"无改进即回滚"很重要：LLM 重写非确定，盲目重写可能把结构改差（73.2→68.2 实测掉分）
- 验证失败命令要回灌 writer 才能真正提升代码分

**v4 最终验证结果（修复后）**：
- 质量分 85.7（A）≥ 阈值 80 → 修复闭环正确不触发（之前 72.3 B 是 bug 造成）
- review 维度 87.9（均分 8.79 × 10 换算），六维：结构 100 / 格式 76 / 事实 86.7 / 密度 100 / 代码 44.3 / 评审 87.9
- 验证器 79 条命令 35 通过（44.3%）——剩余失败绝大多数是真实幻觉（search 命令/UUID ID/npm run dev 等 demo 不存在功能），工具照实报告

**修复的关键 bug（按影响排序）**：
1. **review 标度错误**：reviewer 均分 0-10 制被当 0-100 参与加权 → 评审维度少乘 10，总分虚低（72.3 vs 实际 87.9）。修复：pipeline 里 ×10 换算
2. 验证器把代码块里的报错文本/控制流/目录树/JS 语句当命令执行 → 加 OUTPUT_PATTERNS（Error:/at/✗/目录树字符├│└）、CONTROL_FLOW（for/do/done）、CODE_LANG（const/await/console./行尾;{},）、占位符（yourname/<ID>）、环境变量前缀（VAR=x）
3. 修复闭环无改进仍重写 → 加"分数未提升则回滚旧内容并停止"（v3 实测 72.3→70.4 触发回滚）
4. 验证失败命令未回灌 writer → addVerifyIssues() 并入 issuesByChapter（进修复闭环弹药）

**最终验证过的行为**：五阶段流水线 + --verify 真实验证 + 六维量化 + 阈值修复闭环（触发/回滚/不触发三种路径都见过）+ --template/--baseline/--threshold/--no-fix 参数 + 视觉模型配置骨架（无 key 自动跳过）
